# Security policy

Barye is a research prototype for numerical simulation. It is not hardened against
untrusted input: solvers compiled to WebAssembly and configuration files are assumed
to come from you. Do not run solvers or configurations from sources you do not trust.

To report a security problem, please use GitHub's
[private vulnerability reporting](https://github.com/physical-edge-native/barye/security/advisories/new)
instead of a public issue.
